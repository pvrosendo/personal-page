# Portfolio Paulo Vitor Rosendo

Portfolio profissional em React 19, Vite SPA, TanStack Router, Tailwind CSS
v4 e LinguiJS.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Verificação

```bash
pnpm check
pnpm lint
pnpm build
```

## Estrutura

- `src/pages/`: landing, sobre e projetos.
- `src/components/`: layout e componentes reutilizáveis.
- `src/lib/data.ts`: projetos, experiência, educação e skills mockados.
- `src/lib/i18n.ts`: textos pt-BR e inglês.
- `src/hooks/use-theme.tsx`: persistência do tema e preferência do sistema.

O conteúdo mockado pode ser substituído diretamente em `src/lib/data.ts`.
